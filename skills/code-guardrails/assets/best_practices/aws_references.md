# AWS Well-Architected References

Links to the public AWS Well-Architected guidance. When a change touches AWS infrastructure or services, open the lens that matches the workload and check the change against it. Read the linked page itself; do not rely on a remembered version, since lenses are revised over time.

## Start here

- [AWS Well-Architected Framework](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html): the six pillars every workload is reviewed against.
- [Using lenses](https://docs.aws.amazon.com/wellarchitected/latest/userguide/lenses.html): how lenses extend the Framework for a workload type or industry.
